# LessonRecall

An AI study assistant for course videos: ask questions and get answers with links to the exact minute, practise with quizzes, and follow a study plan.

*Status: in development. Ironhack AI Engineering Bootcamp final project (2026).*

## Project structure

| Folder | What it is | Status |
| --- | --- | --- |
| `ai-service/` | Python FastAPI: ingestion pipeline, agent, evaluation | Day 1: ingestion done |
| `backend-java/` | Spring Boot 3 API (Java 21): login, roles, courses, progress | Day 4 |
| `frontend/` | React (Vite) app | Day 5 |
